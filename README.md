# Mini Social Media App

A small full-stack social media demo built with Node.js, Express and MariaDB.

## Features

- User registration
- Login with sessions
- Profile with avatar upload
- Create posts with text and images
- Likes
- Comments with replies
- Follow / unfollow users
- Following feed
- Real-time posts via Server Sent Events

## Tech Stack

Backend:
Node.js
Express

Frontend:
HTML
CSS
JavaScript

Database:
MariaDB / MySQL

## Installation

1 Clone repository

2 Install dependencies

npm install

3 Create .env file based on .env.example

4 Import db/schema.sql

5 Start server

node server.js

## Note

This repository contains a demo version of the project for portfolio purposes.
Some production features are intentionally omitted.
